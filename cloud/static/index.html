Installationen

Jede Installation entspricht einem Voltibus-System (z. B. einem Raspberry Pi). Nach dem Anlegen erhältst du ein Token – trage es dort unter „Einstellungen → Cloud-Anbindung" ein, damit es seinen Status hierher sendet.
